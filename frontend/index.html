WELCOME TO ACTIONS ARCADE

Your next green run is an adventure.

Mario follows your workflow dependencies. Platforms are jobs, connecting pipes carry progress, and the finish flag is a successful deployment.

  1. Choose a workflow or a recent run in the sidebar.
  2. Select a platform to inspect its steps and logs.
  3. Use Run workflow to simulate a fresh run. Pause, cancel, or re-run it at any time.
  4. Open the failed security run to see Mario stop at a failed job.

This is a local UI shell with simulated runs, logs, and artifacts. It does not connect to GitHub or run code. Runs reset when you reload. Sound is optional. Press / to search or Esc to clear search.
